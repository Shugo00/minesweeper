# マインスイーパー 0.1.0-rc2

[ブラウザで遊ぶ](https://shugo00.github.io/minesweeper/)

Pythonとpygameによるマインスイーパー．通常3難易度と六角形・三角形，練習，ヒント，記録，SE・BGMの個別設定を備える．PCのChrome／Edgeで利用でき，Python導入やサインインは不要．初回は外部CDNから実行基盤を読み込む．

現在は別PCでの受入テスト候補であり，完成判定前である．
